# SpongeBot for Command Palette

**Draft; reservation and Store ID pending.** Proposed package:
`zadjii.SpongeBotforCommandPalette`. Use the [shared fields](../README.md).

## Description

Convert typed text into alternating upper and lower case, then copy the result
from PowerToys Command Palette. Processing happens locally; no network account
is required. Requires PowerToys Command Palette. The extension appears as a
fallback action for typed text, not as a standalone app or top-level page.

## Features and keywords

Alternating-case text; clipboard copy; local processing.
Keywords: text, case converter, clipboard, PowerToys.
