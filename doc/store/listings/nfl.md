# NFL Scores for Command Palette

**Draft; reservation and Store ID pending.** Proposed package:
`zadjii.NFLScoresforCommandPalette`. Use the [shared fields](../README.md).

## Description

View professional football scores and game details from ESPN inside PowerToys
Command Palette. Open game links on ESPN in your browser. Requires PowerToys
Command Palette and internet access. No broadcasts, paid sports subscription,
or unofficial streaming links are supplied. Independent app, not affiliated
with or endorsed by the NFL or ESPN.

## Features and keywords

Scoreboard; game details; official ESPN game links.
Keywords: football, scores, sports, PowerToys.
